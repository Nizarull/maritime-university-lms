## Waterfall Model

### 1. Planning
During this phase, our group identifies the purpose, scope and the goals of the proposed Learning Management System. 

We discussed about the problem linked with managing learning activities and determine how the system can help improve communication and academic management between students, lecturers and administrators. 

We also identify the project timeline, resources and tasks required to ensure the final development of LMS is successful.

### 2. Requirements Analysis
During this phase, our group identifies and documents all the system requirements, including the functional and non-functional requirements. The main users and their expected system output and functions are also identifies in thus phase.

### 3. System Design
During this phase, our group prepares the system architecture and designs the overall structure of the LMS based on the requirements identified in the previous phase. 

Our group will also design the system interface, database structure and system functionalities, which include designing such as login page, users dashboard, course management interface, etc.

### 4. Development 
During this phase, our groups begins the actual development of the LMS based on the system designs prepared earlier.

Each core module will be developed according to its specific requirements such as Login and User Management Module, etc.

The database will also be implemented to store and manage user accounts, course information, learning materials, assignments and submissions, grades and feedback.

### 5. Testing
During this phase, our group conducts testing to ensure that the developed LMS web system functions correctly and meets the identified system requirements. Each module will be tested to identify errors, bugs and unexpected system behaviour.

Any errors identified during testing phase will be corrected before the system proceeds to the development phase.

### 6. Deployment
During this phase, the final LMS web system will be prepared for implementation and made accessible to its intended users. Initial system configurations and database setup will be performed to ensure that the system is ready for use. 

The system will also be checked to ensure that all major functionalities are working properly in the development environment.

### 7. Maintanance
During the final phase, our group will monitor the LMS web system after deployment to ensure that the system continues to function properly. Any errors, bugs or technical issues discovered during usage will be identified and fixed.

Maintenance activities may also include updating system features, improving security, optimisinf system performance and modifying existing functionalities based on the user feedback. 

This phase helps ensure that the LMS web system remains reliable, useful and secure for the target users.
