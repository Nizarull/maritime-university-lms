# Proposed System Overview
(System Architecture, Core Modules, Overall System Functionality)

## 1. System Description
The proposed Learning Management System (LMS) is a web-based platform designed to support teaching and learning activities in University Malaysia Terengganu (UMT). It offers an integrated platform where lecturers, administrative staff and students have access and management of academic information and learning activities. 

The system follows a three-tier architecture consisting of the presentation layer, application layer, and database layer. 
- Presentation layer: Provides the user interface where students, lecturers and administrative staff interact with the LMS through a web browser.
- Application layer: Responsible for system functionalities such as user login, course management, assignment submission, grading, and feedback.
- Database layer: Stores data and manages user accounts, course details, learning materials, assignments, submissions, and academic results.

## 2. Core Modules
- Login and User Management
- Course Management
- Learning and Assesment

## 3. System Objectives
The proposed of Learning Management System (LMS) contains of three main modules:

1. Login and User Management Module

This module manage user login and account information. Users can login and logout of the system using their registered data. This system provides role-based access for administrators, lecturers and students. Users can also manage their profile tab and passwords.

2. Course Management Module

This module allows lecturers to create, update, upload and manage course information. Students can view available courses and enroll in courses according to the system's enrollment rules. Lecturers can upload learning materials while students can access and download their study materials.

3. Learning and Assesment Module

This module supports assignment and assessment activities. Lecturers can create assignments, set submission deadlines, review student submissions, give grades and feedback. For students, they can view assignments, submit their works and check their results and feedback from their lecturers based on their enrolled courses.

## 4. Target Users

1. Students
2. Lecturers
3. Administrators

## 5. Overall System Functionalities
Users - Access the system through the login page. After successful, the system will direct them to the appropriate interface based on their assigned role.
Students - View enrolled courses, access learning materials, view assignments, modules and quizzes, submit works and check their grades and feedback.
Lecturers - Manage their courses, upload learning materials, create assignments, review student submissions (quiz, assignment, modules) and provide grades and feedback.
Administrators - Manage user accounts and overlook the system access according to their assigned role and permissions.
