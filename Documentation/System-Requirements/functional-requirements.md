# Functional Requirements
(services the system should provide, how the system should react to particular inputs, how the system should behave in particular situations, what the system should not do)

Users
1. Users shall be able to login according to their given credentials such as username or email and password.

2. The system shall provide role-based access for students, lecturers and administrators.

3. Users shall be able to log out of the system securely.

4. Users shall be able to view and update their personal profile information.

5. Users shall be able to change their account passwords.

6. The system shall display an appropriate error message when users enter incorrect login credentials.

7. The system shall redirect users to their respective dashboard after successful login.

Students
1. Students be able to search and lookup for the courses they had enroll through the course management module.

2. Students shall be able to view course details and information, including course names, descriptions and lecturers.

3. Students be able to access and download the learning materials uploaded by lecturers.

4. Students be able to view assignments, quizzes and other learning activities provided for their enrolled courses.

5. Students be able to submit their assignments and coursework through the module.

6. Students shall be able to view assignment submission status and deadlines.

7. Students shall be able to check their grades, quiz results and feedback provided by lecturers.

Lecturers 
1. Lecturers shall be able to view and manage the courses assigned.

2. Lecturers can upload, update, hide and delete their learning materials, assignments or quizzes based on their weekly progress according to the course structure.

3. Lecturers be able to create, edit and manage assignments and quizzes for their courses.

4. Lecturers shall be able to set assignment submission deadlines.

5. Lecturers shall be able to review assignments submitted by students.

6. Lecturers can evaluate student submissions and provide grades and feedback.

7. Lecturers shall be able to view students' submission status and assessment results.

Administrators 
1. Admin can register the users such as students, manage users data.

2. Admin can view, search and manage registered user information.

3. Admin be able to update and edit user account details.

4. Admin shall be able to delete or deactivate user accounts when necessary.

5. Admin shall be able to manage user roles and access permissions.

6. Admin be able to monitor and overlook the overall system access and user accounts. (not sure need or not)
