# Interface Design – Learning and Assessment Management

## Overview

This folder contains the interface designs for the Learning and Assessment Management module of the Maritime University LMS.

## Lecturer Interfaces

1. Assessment Dashboard
2. Assignment Management
3. Create / Edit Assignment
4. Quiz Management
5. Create / Edit Quiz
6. Submission Management
7. Submission Review and Grading
8. Assessment Progress

## Student Interfaces

1. Student Assessment Dashboard
2. Student Assignment and Quiz List
3. Student Assignment Details and Submission
4. Student Assessment Results and Feedback
